    Ubicaciones (MIIA, DONNA, BOCALI, LANEA...)

    Sube la hoja de Google descargada como .xlsx (o cualquier Excel) con una pestaña por tabla: columna A = ID, B = artículo, C = ubicación. Cada pestaña con el nombre de una tabla reemplaza la que está guardada.

    Inventario → tabla de ubicaciones

    Para estos inventarios la ubicación se busca por ID artículo en la tabla indicada; los demás quedan sin ubicación.

    Rangos de transportadora

    Según el número de "Guía transportadora": gana la primera fila con guía menor o igual a "Hasta". Nombre vacío = sin transportadora. Una guía mayor que el último rango sale como DESCONOCIDA.

    Los rangos y las tablas se guardan juntos.
